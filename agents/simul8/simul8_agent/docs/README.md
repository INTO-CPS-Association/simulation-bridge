# Simul8 Simulation Agent – Setup Guide

## Overview
<!--markdownlint-disable-->

The Simul8 Agent enables automated batch simulations by
reading input parameters from a YAML configuration file, executing the simulation,
and returning structured results.
This guide explains how to configure your Simul8 simulation file to work with the agent.
<!--markdownlint-enable-->

---

## Batch Simulation Mode

**Batch simulation** runs a complete simulation from start to finish using a
predefined set of inputs, then returns the final results.
No intermediate outputs are produced during execution.

### Key Requirements

1. **Input/Output Sheets**: Create two data sheets in your Simul8 model:
   - `inputSheet` – receives parameters from `input.csv`
   - `outputSheet` – collects results to write to `output.csv`

2. **Visual Logic Blocks**: Add two Visual Logic blocks to your simulation:
   - **On Simulation Open** – loads input data
   - **End Run Logic** – writes output data

3. **YAML Configuration**: The order of parameters for both inputs and outputs
in your YAML request must match the column order in `input.csv`

---

## Step-by-Step Setup

### 1. Create Input and Output Sheets

In your Simul8 model, create two spreadsheet objects:

- **inputSheet** (for reading parameters)
- **outputSheet** (for writing results)

### 2. Add Visual Logic: On Simulation Open

Create a **Simulation Open** Visual Logic block with the following code:

```vb
File to Sheet "input.csv", inputSheet[1,1]
```
<!--markdownlint-disable-->

This loads the `input.csv` file generated by the agent into `inputSheet`, starting at cell `[1,1]`.

### 3. Add Visual Logic: End Run Logic

Create an **End Run Logic** Visual Logic block to write results to `output.csv`.
**Important**: The first row must contain column headers that exactly match the output keys in your YAML configuration.

#### Example: End Run Logic

```vb
' Set column headers (row 1)
SET outputSheet[1,1] = "Total CO2"
SET outputSheet[2,1] = "Total Energy"

' Set values (row 2)
SET outputSheet[1,2] = inputSheet[2,2] + inputSheet[2,3]
SET outputSheet[2,2] = inputSheet[3,2] + inputSheet[3,3]

' Write to file
Sheet to File "output.csv", outputSheet[1,1]
```

**Critical**: The header text in `outputSheet[column, 1]` must **exactly match**
the output field names in your YAML configuration (see below).

**If they don't match, the agent will return `0` for that output.**

## YAML Configuration

### Input Structure

The `inputs` section defines the data passed to the simulation.
The agent writes this as a CSV file with:

- **Row 1** : Column headers (from `columns`)
- **Rows 2+** : Data rows (from `r1`, `r2`, etc.)

Example YAML:

```yaml
simulation:
  file: simulation_batch.s8
  inputs:
    run_time: 500
    columns: [co2, energy]
    r1: [25, 100]
    r2: [25, 200]
  outputs:
    total_co2: Total CO2
    total_energy: Total Energy
```

**Generated `input.csv`**:

```csv
co2,energy
25,100
25,200
```

### Output Structure

The `outputs` section maps YAML keys to CSV column headers from `outputSheet`.
The agent reads `output.csv` and matches columns **by position**
(not by header name), but the header text is still critical for validation.

**Example `output.csv` (written by Visual Logic)**:

```csv
Total CO2,Total Energy
50,300
```

## Header Matching Rules

The agent maps outputs **by column index**
(1st column → 1st output key, 2nd column → 2nd output key, etc.),
but it validates that the header text matches expectations.

### ✅ Correct Setup

**YAML outputs:**
```yaml
outputs:
  total_co2: Total CO2
  total_energy: Total Energy
```

**Visual Logic (outputSheet headers):**
```vb
SET outputSheet[1,1] = "Total CO2"
SET outputSheet[2,1] = "Total Energy"
```

**Result**: Values are correctly mapped to `total_co2` and `total_energy`.

### ❌ Incorrect Setup (Mismatched Headers)

**YAML outputs:**
```yaml
outputs:
  total_co2: Total CO2
  total_energy: Total Energy
```

**Visual Logic (outputSheet headers):**
```vb
SET outputSheet[1,1] = "CO2 Total"  ❌ Does not match "Total CO2"
SET outputSheet[2,1] = "Energy"     ❌ Does not match "Total Energy"
```

**Result**: The agent cannot validate the headers and may return `0` for mismatched fields.

## Complete Example

### YAML Configuration

```yaml
simulation:
  name: carbon_energy_sim
  file: simulation_batch.s8
  inputs:
    run_time: 500
    columns: [co2, energy]
    r1: [25, 100]
    r2: [25, 200]
  outputs:
    total_co2: Total CO2
    total_energy: Total Energy
  bridge_meta: test_run
  request_id: req_001
```

### Visual Logic: On Simulation Open

```vb
File to Sheet "input.csv", inputSheet[1,1]
```

### Visual Logic: End Run Logic

```vb
' Define output headers (must match YAML outputs)
SET outputSheet[1,1] = "Total CO2"
SET outputSheet[2,1] = "Total Energy"

' Calculate values from input data
SET outputSheet[1,2] = inputSheet[2,2] + inputSheet[2,3]  ' Sum of co2 values
SET outputSheet[2,2] = inputSheet[3,2] + inputSheet[3,3]  ' Sum of energy values

' Write results to CSV
Sheet to File "output.csv", outputSheet[1,1]
```

### Expected Files

**input.csv** (generated by agent):
```csv
co2,energy
25,100
25,200
```

**output.csv** (written by simulation):
```csv
Total CO2,Total Energy
50,300
```

**Agent Response**:
```json
{
  "status": "success",
  "outputs": {
    "total_co2": "50",
    "total_energy": "300"
  }
}
```

## Troubleshooting

| Issue | Cause | Solution |
|-------|-------|----------|
| Output field returns `0` | Header mismatch between Visual Logic and YAML | Ensure `outputSheet[column,1]` text **exactly matches** the YAML output field description |
| `input.csv` not found | Missing "On Simulation Open" logic | Add Visual Logic: `File to Sheet "input.csv", inputSheet[1,1]` |
| `output.csv` not created | Missing "End Run Logic" | Add Visual Logic: `Sheet to File "output.csv", outputSheet[1,1]` |
| Wrong column order | YAML columns don't match inputSheet usage | Verify column order in YAML `columns` matches how Visual Logic reads `inputSheet` |
